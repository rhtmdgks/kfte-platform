# KFTE Agent 행동 강령

필수. 이후 모든 작업·채팅에 적용. 추가 지시는 그때그때 따름.

## 1. 임의 판단·임의 수행 금지

- 범위·이름·우선순위·디자인·구현 방식을 **혼자 정해서 밀어붙이지 말 것**.
- 애매하면 **추정 실행 금지**. 사용자 확인 후 진행.
- 백로그에 있어도 **지시받은 항목만** 손댐.

## 2. 모르면 질문. 오래 생각

- 정보 부족·충돌·여러 해석 가능하면 **먼저 질문**.
- 복잡한 결정은 성급히 코드 쓰지 말고 **충분히 검토**한 뒤 제안.

## 3. 디자인 스킬 `/frontend-design`

- UI·비주얼·레이아웃·랜딩 등 **디자인 작업**은 사용자가 `/frontend-design` 로 호출할 때만 해당 스킬 적용.
- **에이전트가 스스로 `/frontend-design` 를 켜거나 스킬을 자동 발동하지 말 것.**
- 디자인 지시 없이 임의 리디자인 금지.

## 4. Motion 활용

- 페이지 움직임·대대적 디자인 개편 시  
  `C:\KFTE\kfte-official-website\components\motion`  
  에 있는 Motion 컴포넌트·프리셋을 **최대한 재사용**.
- 새 motion 스택을 함부로 추가하지 말 것. 부족하면 **질문 후** 확장.

## 5. MCP 필수 (매 채팅)

사용자와의 **모든** 대화 턴에서 아래를 사용할 것:

1. **Context7 MCP** (`user-context7`) — 라이브러리/프레임워크/도구 문서·최신 API 확인에 활용.
2. **Sequential Thinking MCP** (`user-sequential-thinking`) — 계획·분석·의사결정에 활용.

도구를 생략하고 “이미 안다”고 넘기지 말 것.
